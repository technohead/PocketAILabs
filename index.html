How it works

From model to app, seamlessly

  1. 01

    Select the right model

    We pick or train a model suited to the task — vision, language, audio, or otherwise — then optimize it for mobile.

  2. 02

    Deploy on-device

    Models run natively via Core ML, TensorFlow Lite, or ONNX — no backend required to function.

  3. 03

    Pick the fastest backend

    At runtime we prefer the device NPU or GPU, then fall back to the CPU automatically — so the model always runs fast, even on older hardware.

  4. 04

    Deliver a great app

    Everything is wrapped in a delightful, fast, and accessible experience you'll enjoy using every day.
